# EMK SYSTEM™ · Peace Protocol — DESIGN.md

The site is a protocol the visitor runs. Every page is a step; every interaction completes part of it.

## Overview
- Near-black field. The photograph is the card: product photos sit full-bleed, square-cornered, no shadow (borrowed from Nike's product-led pacing, nothing else copied).
- Towering campaign type set onto photography: Archivo 500, tight tracking, sentence case.
- Champagne is never decoration: only the active state (ring, scan line, progress) and the one solid action.
- A persistent Protocol bar carries the visitor's progress across pages.

## Colors
- `--bg` #0a0a0a field · `--surface` #141311 raised · `--ink` #e8e0cc cream type · `--muted` #a9a294 secondary · `--accent` #d4c3a3 champagne active/action · `--accent-ink` #0a0a0a.

## Typography
- Archivo 400/500/600 (UI + display). Bodoni Moda 500 for the EMK wordmark only. Noto Naskh Arabic, Noto Serif Armenian for the scripts. All self-hosted.
- Steps: 14 small · 17 body · clamp(20–26) lead · clamp(40–104) head · clamp(72–220) display.

## Shape & spacing
- Radius 0 everywhere. 8px base unit; sections 120–200px apart on desktop, 96px on phones. Margins 16–32px.

## Motion
- Ease-out curves (`power3/power4/expo.out`); scrubbed motion uses `none`.
- Every tap answers within 100ms. Nothing uses the same entrance twice in a row.
- Reduced motion: final states, no grain, no particle morphs.

## Components
- Button (solid champagne, press 0.97 spring, magnetic on mouse) · text link (underline draws in) · roll link (letters roll up) · Protocol bar · full-screen menu · hotspot dot · scan line · size dial.
